# 지식베이스 원본 자료

`app/rag/ingest.py`의 `SOURCE_REGISTRY`가 이 폴더의 인덱싱 정책(제목·분류·업종범위·포함여부)을 관리한다.
파일을 추가·교체하면 반드시 레지스트리도 같이 수정하고 `python -m app.rag.ingest`를 다시 실행한다.

## 형식 규칙

- **자료는 전부 Markdown(`.md`)으로 넣는다.** `.pdf`, `.docx`는 인덱싱되지 않고 실행 로그에 `[건너뜀]`으로 찍힌다.
  PDF 텍스트 추출은 표를 줄바꿈된 평문으로 뭉개서 "분쟁유형 / 해결기준 / 비고"의 열 대응이 사라졌다.
  Markdown 표는 이 대응이 남아서 LLM이 행·열을 읽을 수 있다.
- 파일명은 원본 자료의 이름을 그대로 쓴다. `SOURCE_REGISTRY`의 키가 이 파일명이므로, 파일명을 바꾸면 키도 같이 바꾼다.
- 변환 시 원문 쪽 표시는 `## 원문 8쪽` 또는 `<!-- 원문 PDF 8쪽 -->`로 남긴다.
  ingest가 이 표시를 섹션 제목이 아니라 `page` 메타데이터로 빼낸다(근거 위치가 "원문 8쪽"이 되지 않게).
- 변환 전 원본(PDF 등)을 같이 두고 싶으면 `_`로 시작하는 폴더(`_archive/`)에 넣는다. 수집에서 통째로 제외된다.

## 빠진 자료 (2026-09-17 기준)

아래 두 문서는 이전 구성에 있었으나 지금 폴더에 없다. 필요하면 다시 넣고 레지스트리에 등록한다.

- **소비자기본법 시행령 [별표1] 일반적 소비자분쟁해결기준** — 품목별 기준(별표Ⅱ)의 *상위 원칙*이다.
  환급금액 산정 기준(영수증·통상적인 가격), 다른 법령 우선 적용, 유사품목 준용, 소비자 선택권의 근거가 여기에 있다.
  `recommendation_graph.PINNED_SECTIONS`의 `"[별표 1]"` 고정 항목은 이 문서를 겨냥한 것이라, 지금은 아무것도 매칭되지 않는다.
  공정거래위원회 「소비자분쟁해결기준」 배포본 PDF 앞 3쪽(소비자기본법 제16조 / 시행령 제8조·제9조 / 시행령 [별표1])이 원 출처다.
- **편의점 고객응대 실무 매뉴얼** (`manual`, convenience_store) — 공식 자료를 편의점 현장용으로 재구성한 사내 실무안이었다.
  단순변심 환불·영수증 미지참·카드결제 취소처럼 공식 고시에 없는 항목의 유일한 근거였다.

## 환불 응대에서 "명시된 자료 없음"인 항목

아래는 위 자료 전체를 검색해도 근거가 없는 항목이다. AI가 이 부분을 단정하면 근거를 지어낸 것이므로,
`needsHumanReview`를 올리고 관리자에게 인계해야 한다.

- 식료품이 **소비자 보관 부주의로 변질**된 경우의 사업자 면책 — 식료품 항목에는 없음.
  (시행령 [별표1] 제1호 가목에 "소비자의 취급 잘못" 면책이 있으나, 이는 *품질보증기간 중 수리·교환·환급 비용* 부담에
  관한 규정이라 식품 변질에 그대로 적용된다고 볼 수 없음. 게다가 지금은 그 시행령 별표1 자체가 폴더에 없다)
- 냉장·냉동 보관 온도 수치(0~10℃ 등) — 「식품의 기준 및 규격」(식품공전) 소관이며 이 폴더에 없음
- 단순변심 환불, 영수증 미지참 처리, 카드결제 취소 절차 — 공식 고시에 없음.
  편의점 실무 매뉴얼이 빠지면서 사내 기준 근거도 함께 사라졌다
