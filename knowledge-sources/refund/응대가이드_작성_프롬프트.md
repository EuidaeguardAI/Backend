## 프롬프트 원문

'근거' 폴더에 있는 PDF 자료를 기반으로 아래 시나리오에 대한 응대가이드를 만들어줘.

**참고 자료 (근거 폴더)**
1. 소비자분쟁해결기준 개정안 전문(본문).pdf
2. [별표1][별표2] 품목별 해결기준(2024.12.27 시행).pdf
3. [별표3][별표4] 품목별 품질보증기간 및 부품보유기간(2024.12.27.시행).pdf
4. 식품등의 표시기준(제2025-60호, 2025.8.29.).pdf
5. 고객응대근로자_건강보호_가이드(2019).pdf

**매장 정보**
- 가게 형태: [예: 작은 홈플러스]

**손님 상황(시나리오)**
- [예: 손님이 3일 전 요구르트를 구매, 2개 마시고 나머지 3개를 실온에 3일간 보관. 3일 뒤 방문하여 "요구르트가 왜 이렇게 빵빵해졌냐, 환불해달라"고 요구]

**요청 사항**
1. 이 상황을 위 자료들만 근거로 답변 가능한지 판단해줘.
2. 답변이 어려운 부분(자료에 명시되지 않은 부분)은 "명시된 자료 없음"이라고 정확히 표기해줘.
3. 아래 3단계로 나눠서 실제 매장에서 쓸 수 있는 응대 멘트를 만들어줘.
   - ① 자료에 근거해 설명 가능한 부분 (조문/표 인용)
   - ② 자료에 없어서 매장 자체 판단이 필요하다고 안내하는 부분
   - ③ 실제로 직원이 현장에서 직접 판단을 내려야 하는 상황을 가정한 대응 멘트 (사실관계 확인 → 판단 근거 설명 → 애매할 때 에스컬레이션 → 고객이 강하게 항의할 때 직원 보호 멘트)
4. 필요하면 자료에 없는 부분은 추가로 웹 검색(식약처, 법령정보센터 등 공식 출처)을 통해 보완하고, 그 결과를 근거 폴더 문서와 명확히 구분해서 표시해줘(어느 게 폴더 안 자료 근거이고 어느 게 외부 검색 근거인지).

## 이 프롬프트가 만들어내는 결과물의 구조 (참고용)

1. **결론**: 답변 가능 여부 (완전/부분/불가)
2. **자료 근거 표**: 문서명 + 조문/항목 + 인용 내용
3. **"명시된 자료 없음" 항목 리스트**: 상식적 추론과 실제 규정을 구분
4. **응대 멘트 3단계** (위 요청사항 3번 형식)
5. **(선택) 직원 보호 관점 멘트**: 고객응대근로자 건강보호 가이드 기반, 고객이 격해질 때만 사용

## 이번 세션 실제 적용 사례 (요구르트 환불 건)

- **결론**: 부분적 답변 가능
- **자료 근거**:
  - 별표Ⅱ 식료품(낙농제품류): "부패, 변질 → 제품교환 또는 구입가 환급"
  - 식품등의 표시기준 제3조(정의) 라목: "'소비기한'이란 표시된 보관방법을 준수할 경우 안전에 이상 없는 기한"
  - 같은 고시 유가공품류 표시사항: "보관방법(해당하는 경우에 한함)" 표시 의무
- **명시된 자료 없음**:
  - 소비자 보관 부주의로 인한 변질 시 사업자 면책 조항 (전자제품엔 있으나 식료품엔 없음)
  - 구체적 냉장 보관 온도 수치(0~10℃ 등) — 이건 식품공전(식품의 기준 및 규격) 소관이며 근거 폴더에는 없음
- **응대 멘트**: 3단계(자료 근거 설명 / 판단 필요 안내 / 직접판단 시나리오) + 직원 보호 멘트 완성
